# 발표 코칭 RAG 지식 문서

이 디렉토리의 Markdown 문서는 AI 발표 코칭과 발표 문맥 채팅에서 참고 지식으로
검색된다. 문서는 시스템이 계산한 점수나 측정 근거를 변경하지 않으며, 코칭 방향과
연습 방법을 보완하는 용도로만 사용한다.

## 문서 형식

```markdown
---
id: unique_document_id
category: audio
target_metric: wpm
related_services:
  - practice_coaching
  - chat
priority: high
version: 1.0
---

# 문서 제목

문서 내용
```

필수 권장 필드는 `id`, `category`, `target_metric`, `related_services`, `priority`,
`version`이다. `id`는 디렉토리 안에서 고유해야 한다.

## 검색 방식

- 발표 목적, 청중, 핵심 메시지, 규칙 기반 개선 항목을 검색 질의로 사용한다.
- 측정 가능하며 80점 미만인 지표의 문서를 우선 검색한다.
- 측정 불가 항목은 낮은 점수로 취급하거나 검색 우선순위에 넣지 않는다.
- 발표 문맥 채팅에서는 질문 답변과 안전·개인정보 문서를 추가 우선한다.
- 한 요청에는 기본 최대 5개 문서, 문서별 최대 1,800자를 전달한다.

## 주의사항

- 문서의 예시 점수, 가중치, 임계값은 현재 코드 점수 계산 기준을 대체하지 않는다.
- 문서 내용은 측정 근거가 아니며 LLM 응답의 `evidence`로 사용할 수 없다.
- 실제 논문이나 외부 기준을 추가할 때는 출처와 적용 한계를 함께 기록한다.
- 민감한 개인정보나 사용자별 분석 결과를 이 디렉토리에 저장하지 않는다.
- Markdown 심볼릭 링크는 검색 대상에서 제외된다.
