# 연습 코칭 운영 가이드

## 기능 범위

연습 코칭은 완료된 발표 분석 결과에 발표 목적, 청중, 핵심 메시지, 목표 시간,
반복 연습 시리즈 정보를 연결한다. 기본 분석 결과와 연습 코칭은 별도 요청으로
조회하므로 코칭 생성이 실패해도 점수, 피드백, 섹션, 타임라인은 계속 확인할 수 있다.

발표 목적 정의는 백엔드 `GET /analyze/practice/purposes` 응답을 단일 출처로 사용한다.
프론트엔드는 API 요청이 실패한 경우에만 최소 대체값을 사용한다.

## 사용자 흐름

1. 업로드 화면에서 발표 목적과 연습 컨텍스트를 입력한다.
2. 분석 작업 생성 후 `PUT /analyze/practice/{result_id}`로 컨텍스트를 저장한다.
3. 결과 화면은 기본 분석 결과를 먼저 표시하고 `GET /analyze/practice/{result_id}`로
   연습 계획, 예상 질문, 내용 분석을 별도로 요청한다.
4. 예상 질문을 선택하면 질문은 AI 청중의 질문으로 표시되고 답변 입력창은 비어 있다.
5. 사용자가 답변을 제출하면 Ollama 코치가 명확성, 근거, 간결성, 설득력을 평가한다.
6. 성장 화면은 동일 목적과 동일 연습 시리즈의 결과만 이전 결과와 비교한다.

## 데이터와 비교 규칙

- 연습 컨텍스트는 `Back/practice_contexts/{result_id}.json`에 저장한다.
- `series_name`이 있으면 사용자, 발표 목적, 정규화된 시리즈 이름으로 안정적인
  `series_id`를 생성한다.
- 기존 데이터에 `series_id`가 없으면 동일 목적과 대소문자를 무시한 동일
  `series_name`을 대체 비교 기준으로 사용한다.
- 결과 삭제, 계정 삭제, 자동 보존 기간 정리는 연결된 연습 컨텍스트도 함께 제거한다.
- 사용자 데이터 내보내기는 연습 컨텍스트와 계산된 코칭 결과를 포함한다.

## 점수와 분석 한계

- 감지되지 않거나 데이터가 부족한 지표는 `0점`이 아니라 `측정 불가`로 처리한다.
- 측정 불가 지표는 종합 점수 가중치에서 제외하고 사용 가능한 지표로 가중치를
  재계산한다.
- 발표 내용 분석은 Whisper 발화 시점, 위치, 연결 표현을 사용하는 휴리스틱
  보조 분석이다. 의미 판단 결과로 단정하지 않으며 화면에서 신뢰도와 근거 문장을
  함께 표시한다.
- 얼굴 방향 안정성은 카메라 기준 얼굴 방향 추정이며 실제 시선 추적 결과가 아니다.

## 운영 점검

프로젝트 루트에서 다음 명령을 실행한다.

```bash
./scripts/check-practice-contexts.sh
./scripts/verify.sh
./scripts/verify-service.sh
./scripts/verify-browser-e2e.sh
```

`check-practice-contexts.sh` 결과의 `orphan_practice_contexts`가 `0`이 아니면 결과가
존재하지 않는 컨텍스트 파일이 남아 있다는 의미다. 원인을 확인하기 전 파일을
자동 삭제하지 않는다.

운영 점검 시 다음을 함께 확인한다.

- 코칭 API 실패 상태에서도 기본 분석 결과와 타임라인이 표시되는가
- 측정 불가와 실제 낮은 점수가 화면에서 구분되는가
- 예상 질문 선택 후 답변 입력창이 비어 있는가
- 다른 목적 또는 다른 시리즈 결과가 성장 비교에 포함되지 않는가
- 사용자 데이터 내보내기에 연습 목적, 목표, 개선 계획이 포함되는가
- 결과 삭제 후 연결된 연습 컨텍스트가 남지 않는가
