# 프론트엔드 UI/UX QA 보고서

- **점검일**: 2026-07-16
- **대상**: `frontend` (React 19 + Vite + Tailwind v4), 로컬 실행 `http://localhost:5173`
- **점검자 관점**: 웹 프론트엔드 QA
- **점검 해상도**: PC 1440px / 태블릿 768px / 모바일 390px
- **점검 방법**: 실제 브라우저에서 각 페이지를 세 해상도로 렌더링. 같은 출처(localhost) iframe에 목표 폭을 강제 주입해 미디어 쿼리를 정확히 반응시킨 뒤, (1) 가로 오버플로우(`scrollWidth - 뷰포트폭`), (2) 깨진 이미지(`naturalWidth===0`), (3) 잘린 텍스트/뷰포트 밖 요소, (4) 링크 href와 라우트 매칭, (5) 텍스트 대비(WCAG 명암비)를 수치로 측정.

> 참고: 이번 점검은 로그인 없이 접근 가능한 **공개 페이지**를 대상으로 했습니다. 업로드/결과/계정/상태/관리자 페이지는 로그인이 필요해 이번 회차에서 점검하지 못했습니다(마지막 "미점검 항목" 참조).

## 2. 발견된 문제

| # | 심각도 | URL / 위치 | 해상도 | 증상 (캡처 위치) | 원인 | 수정 제안 |
|---|---|---|---|---|---|---|
| 1 | 🔴 Critical | `/` 홈 — 히어로 제목 및 모든 섹션 제목 | 전 해상도 | 히어로 "발표는 감이 아니라, 데이터로 완성됩니다" 및 "발표의 모든 순간을…", "결과 상세 화면에서…", "3단계면 충분합니다", "자주 묻는 질문", "지금, 데이터로 발표를 완성하세요" 제목이 **거의 안 보임**. 측정 명암비 **1.26~1.31** (WCAG AA 기준 4.5:1). 글자색 `#2B2420`, 배경 `#090807`. (화면: 홈 상단 히어로 영역 — 아이브로우 "AI 발표 코칭"과 본문은 보이지만 큰 제목만 사라짐) | `frontend/src/index.css`의 전역 규칙 `h1, h2 { color: var(--text-h) }`(`--text-h:#2B2420`)가 **cascade layer에 속하지 않은(unlayered)** 규칙이라, Tailwind v4의 `text-text-primary` 유틸리티(`layer(utilities)`)보다 우선순위가 높아 **밝은 색 지정을 덮어씀**. h3에는 전역 색 규칙이 없어 정상(명암비 16). 근본 원인은 index.css에 남아있는 **라이트 테마 토큰**(`--text/--text-h/--bg`)과 실제 다크 테마의 충돌. | (권장) `index.css`의 `h1,h2` 색상 지정을 제거하거나 base 레이어로 이동. 예: `@layer base { h1,h2 { color: var(--color-text-primary); } }` 로 감싸 유틸리티가 정상 override 되게 함. 또는 라이트 테마 토큰 `--text/--text-h/--bg`를 다크 테마 값으로 교체. |
| 2 | 🟡 Minor | `/privacy` — 데이터 보존 항목의 `<code>` | 모바일 390 | 긴 코드 토큰 `STORAGE_RETENTION_ORIGINAL_VIDEO_DAYS`(38자, 공백 없음)가 화면 폭을 **20px 초과**(우측 끝 410px > 390px) → **가로 스크롤 발생**. (화면: privacy 본문 "데이터 보존" 문단의 인라인 코드) | `index.css`의 `code` 스타일이 `overflow-wrap: normal`이라 긴 무공백 문자열이 줄바꿈되지 않음. | `code` 규칙에 `overflow-wrap: anywhere;`(또는 `word-break: break-word;`) 추가. |
| 3 | 🟡 Minor | `/` 등 — 주황 기본 버튼 `무료로 시작하기` / 상단 "홈" 활성 탭 | 전 해상도 | 밝은 글자 `#F5EFE8` on 주황 `#C85A19`, 명암비 **3.73** (일반 텍스트 AA 4.5:1 미달, 큰 텍스트 3:1은 충족). (화면: 히어로 좌측 주황 버튼) | 브랜드 주황이 밝은 글자 대비 부족. | 버튼 배경을 조금 더 진한 주황(`--color-primary-deep #7A2F0B` 계열)으로 하거나 글자를 순백으로. 최소 4.5:1 확보. |
| 4 | 🟡 Minor | `/terms`, `/privacy` — 푸터 법적 링크 | 전 해상도 | 푸터 "개인정보처리방침/이용약관" 링크 색 `#776E66`(text-muted) on `#090807`, 명암비 **4.01** — AA 경계값. | muted 색 토큰이 배경 대비 낮음. | 푸터 링크에 `text-text-secondary`(#B7ADA4, 대비 상승) 적용 권장. |

## 4. 미점검 항목 (로그인/권한 필요)

다음 페이지는 로그인이 필요해 이번 회차에서 점검하지 못했습니다. QA 도구가 직접 계정 생성·비밀번호 입력을 수행하지 않는 것이 원칙이라, 아래 중 하나가 준비되면 이어서 점검하겠습니다.

- 일반 사용자 페이지: `/onboarding`, `/upload`, `/results`, `/results/:jobId`, `/account`, `/status`
- 관리자 페이지: `/admin`, `/admin/users/:userId`, `/admin/audit-logs`

**필요 협조**: 연결된 브라우저에서 일반/관리자 계정으로 직접 로그인해 주시거나, 시드(seed) 스크립트로 테스트 계정을 만들어 주시면 로그인된 세션 위에서 동일 기준으로 점검을 이어갑니다.

## 5. 표준 보고 형식 (프로젝트 규칙)

- **확인한 현재 상태**: frontend가 localhost:5173에서 정상 구동. 공개 페이지 8종 + 404 렌더 정상. 이미지는 전량 SVG/CSS.
- **발견한 문제**: 홈 제목 다크-온-다크(Critical) 1건, 경미 이슈 3건(모바일 코드 오버플로우, CTA·푸터 대비).
- **수정한 항목**: 전역 타이포그래피·링크 규칙을 cascade base layer로 이동하고 제목 고정 색을 제거했다. 긴 `code` 토큰 줄바꿈, CTA·활성 탭 배경 대비, 푸터 링크 색상도 수정했다.
- **남은 위험**: 로그인·관리자 페이지는 아직 미점검이다.
- **실행한 검증**: 수정 후 공개 페이지를 실제 브라우저에서 재측정하고 frontend 전체 lint/test/build를 실행했다.
- **다음 우선순위**: 로그인 세션을 준비한 뒤 보호 페이지와 관리자 페이지를 동일 기준으로 QA한다.
